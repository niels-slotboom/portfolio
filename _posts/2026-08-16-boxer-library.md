Boxer is a lightweight C++ shared library that enables in-situ visualisation of AMReX grid hierarchies. Passing an `amrex::AmrMesh& mesh` reference (which `amrex::AmrCore` derives from) to `boxer::show(mesh, ngrow)` opens an interactive OpenGL-based 3D view in a separate window which displays the current box structure. Its primary benefits over standalone visualisation software are its minimal API, zero reliance on plotfiles, and zero required setup. Source code, build instructions, as well as CMake setup are available on my [GitHub repository](https://github.com/niels-slotboom/boxer.git).
<!--more-->

Shown below is an example grid hierarchy generated for the function
\\[
    \phi(x,y,z) = \frac{1}{\sqrt{x^2 + y^2 + z^2 + 0.001}},
\\]
with tagging performed using a generalised Löhner estimate,
\\[
    \text{tag if} \quad \frac{\Delta x^4 \Vert H \Vert_F^2}{\Delta x^2 |\nabla \phi|^2 + \phi_0^2} > 0.04.
\\]
Here, $$\Delta x$$ is the grid spacing along any axis, $$H$$ the Hessian of $$\phi$$, and $$\Vert H \Vert_F^2$$ its Frobenius-norm.

The Boxer window allows you to set the range of levels to be displayed---in the above example, levels 1--6 are displayed, with level 0 being hidden. Further, you can choose to display the halo regions/ghost zones of the grid, and enable a slow automatic rotation of the view.

I developed this library as a tool to make debugging easier while I am learning to use AMReX. Although it is always possible to just print out the metadata of the boxes generated by `amrex::AmrCore`, it is far more convenient to have an interactive view that displays them in the three dimensions they live in---which is how the idea behind Boxer came into existence. The tool's name is literal, but it describes its modest task well---it's a thing that deals with _boxes_, hence it's a _boxer_.
